ผลงานและโปรเจกต์ (Portfolio)

รวบรวมชิ้นงานจริงที่ได้รับการออกแบบและพัฒนาด้วยเทคโนโลยีที่ทันสมัย มีคุณภาพ และตอบโจทย์ทางธุรกิจ

Web Desing UX/UI

ออกแบบ UX/UI เกี่ยวกับแอปสำหรับนักท่องเที่ยว

การออกแบบ UI และ UX สำหรับแอปพลิเคชันสำหรับนักท่องเที่ยว มีระบบค้นหาสถานที่ แผนที่นำทาง การจองโรงแรม และการวางแผนทริปเดินทางอย่างเป็นระบบ

ดูรายละเอียดผลงาน
Mobile App

ออกแบบ Application เกี่ยวกับการคัดแยกขยะ

การออกแบบและพัฒนาแอปพลิเคชันบนสมาร์ทโฟนเพื่อส่งเสริมการคัดแยกขยะอย่างถูกต้อง มีระบบแนะนำประเภทขยะ ระบบแสกนขยะเพื่อคัดแยกขยะ และส่งเสริมพฤติกรรมที่เป็นมิตรต่อสิ่งแวดล้อม

3D Weapon Asset Design

งานปั้นโมเดลขวาน 3D

ผลงานการขึ้นรูปโมเดล 3 มิติประเภทอาวุธขวาน ด้วยโปรแกรม Blender จัดวางโครงสร้าง Mesh ที่เหมาะสม และทำ Texture และการจัดแสงเพื่อนำไปใช้ต่อในเกมหรือสื่อภาพเคลื่อนไหว

3D Character Mode

การออกแบบและขึ้นรูปโมเดลตัวละคร 3 มิติ

ผลงานการปั้นและออกแบบโมเดลตัวละคร 3 มิติด้วยโปรแกรม ZBrush เน้นการสร้างรูปทรง รายละเอียดกายวิภาค และการจัดโพสท่าทางของตัวละคร เพื่อนำไปพัฒนาเป็นตัวละครในเกมหรือสื่อแอนิเมชัน
